SMS QR Code Generator

An SMS QR code opens the messaging app with a number and optional message pre-filled.

What is an SMS QR code?

It encodes an sms: URI so scanning opens a draft text message to the given number.

How to create one

Enter the phone number and, optionally, message text, then generate the code.

How to scan it

Scanning opens the default messaging app with the draft ready to send.

Common uses

Opt-ins, quick feedback lines, and event check-ins.
