Plain Text QR Code Generator

A text QR code stores raw text directly, so scanning it displays the text itself rather than opening a link.

What is a text QR code?

Instead of a link, the QR code holds whatever text you type — useful for notes, instructions, serial numbers or short messages.

How to create one

Type or paste your text into the box above; the character counter helps you keep it scannable at a reasonable size.

How to scan it

Any camera-based QR scanner will display the decoded text on screen after scanning.

Common uses

Product info cards, inventory tags, event details, or any message you want available offline without hosting a web page.
