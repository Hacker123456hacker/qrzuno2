Wi-Fi QR Code Generator

A Wi-Fi QR code stores your network name, password and security type in a standard format most phones understand natively.

What is a Wi-Fi QR code?

It encodes your network's SSID, password and encryption type so a phone camera can offer to join the network directly.

How to create one

Enter your network name and password, choose the security type, and QRZuno builds the standard WIFI: payload for you.

How to scan it

Most modern Android and iPhone cameras recognize Wi-Fi QR codes automatically and prompt to connect.

Common uses

Cafes, offices, Airbnbs, and home entryways use printed Wi-Fi QR codes so guests never have to ask for or type a password.
